Yukawa Potential, Reduced Units,
and System Setup

Paper definition → Fortran implementation → N = 1000 inputs
Working note for the MC–NPT reconstruction · 8 July 2026
Purpose. This note derives the hard-core signed Yukawa model used by Sanz et al. (PRL 99, 055501, 2007), maps it to the present Fortran source, and gives the complete conversion between packing fraction, number density, volume, and box length. It also records which input values matter for a fresh configuration and which are overridden by a restart.

1. Physical model in the paper

The system is an equimolar binary mixture of monodisperse spheres. Every particle has diameter σ and charge magnitude Ze; the two types carry opposite signs. Define sij = +1 for equal charges (1–1 or 2–2) and −1 for opposite charges (1–2).

uij(r)/(kBTphys) =
+∞r < σ
sij [Z²λB / {σ(1+κσ/2)²}] exp[−κ(r−σ)]/(r/σ)σ ≤ r < rc
0r ≥ rc

Here λB = e²/(εskBTphys) is the Bjerrum length. For the electrolyte convention in the paper, κ = √(8πλBρsalt). The chosen model parameters are κσ = 6 and rc = 3.5σ. The exponential is referenced to contact, r = σ.

2. Contact-energy scale and reduced variables

εY ≡ kBTphys Z²λB / [σ(1+κσ/2)²]

The paper’s reduced temperature is the inverse contact coupling:

T* = kBTphys/εY = σ(1+κσ/2)²/(Z²λB)

Therefore βεY = 1/T*. Increasing T* weakens the interaction in thermal units.

With r* = r/σ, κ* = κσ, and u* = u/εY:

u*ij(r*) = +∞r* < 1
u*ij(r*) = sij exp[−κ*(r*−1)]/r*1 ≤ r* < r*c
u*ij(r*) = 0r* ≥ r*c
Metropolis exponent: −βΔU = −ΔU*/T*

The code stores U* and sets BETA=1/TEMP; consequently the input TEMP is T*.

3. Exact map to the Fortran source

With sig=1, kappa=6, and rc=3.5, the actual finite interaction is

u*ij(r) = sij exp[−6(r−1)]/r,   1 ≤ r ≤ 3.5.

Source/ener.f evaluates pref=EXP(-KAPPA*(R-sigma)) and En=Isign*pref/(R/sigma). Below σ it returns 10²⁰, effectively forbidding overlap; beyond rc it returns zero. The production potential is truncated, not shifted: tailco=.false. and shift=.false..

Charge sign, periodicity, and total energy

Source/eneri.f chooses +1 when the particle types match and −1 otherwise, then applies the minimum-image convention in each Cartesian direction. Source/toterg.f sums each unordered pair once:

U* = Σi<j u*ij(rij).

A new lattice receives alternating type IDs, giving 500 particles of each type for N=1000. Restarts preserve each type explicitly.

Pair virial

−r du*ij/dr = sije−κ(r−σ)σ(κ+1/r)

This is exactly the virial expression in ener.f. The sampled continuous estimator is

p*continuous = ρ*T* + [Σi<j(−rijdu*ij/drij)]/(3V*).
Pressure warning. This estimator omits the discontinuous hard-core contact contribution. It is not the complete mechanical pressure. The imposed p* is nevertheless used correctly in the NpT acceptance rule.

Legacy Lennard–Jones names

eps sig mass rc kappa
1.0 1.0 1.0 3.5 6.0

eps, EPS4, and EPS48 are inherited Lennard–Jones names. The Yukawa energy routine does not multiply by eps. In current runs eps=1 is a placeholder; the Yukawa energy unit is εY, and temperature enters through BETA=1/TEMP.

4. Packing fraction → density → volume → box

The volume of one diameter-σ sphere is πσ³/6. Therefore

η = N(πσ³/6)/V = (π/6)ρ*
ρ* = 6η/π    |    V* = N/ρ* = Nπ/(6η)    |    L* = [Nπ/(6η)]1/3

These are geometric conversions, independent of the pair potential. Changing N at fixed η changes V and L, but not ρ*.

Worked example: paper state, N=1000 and η=0.526

ρ* = 6(0.526)/π = 1.0045860008
V* = 1000/1.0045860008 = 995.4349346
L* = (995.4349346)1/3 = 9.98475990

A newly generated box at the paper’s quoted metastable-liquid packing fraction should therefore use rho=1.004586. Using rho=0.526 would incorrectly treat packing fraction as number density and yield η≈0.2754.

5. How initialization really uses density

Source/readdat.f initially calculates L*=(N/ρ*input)1/3, but subsequent behavior depends on ibeg.

ibegConfiguration modeWhat the density line does
0Generate a new latticeThe input ρ* determines the box.
1Normal restartThe restart box is retained. The code replaces the nominal density by N/L³. The density input does not rescale coordinates.
2Rescaled restartThe restart coordinates and box are deliberately rescaled to the requested input density.
Current workflow. Clean production uses ibeg=1. Thus the line 1000 1.0 1.0 18.0 'sc' does not force ρ*=1. The restart box is authoritative, explaining why a run can start near ρ*=1.037.

The NpT controls are N, T*, and p*. An initial η only constructs or rescales a starting box. Subsequent accepted volume moves change density.

6. NpT volume move in reduced units

The code proposes uniformly in logarithmic volume:

ln V*n = ln V*o + (ξ−½)Vmax,   0≤ξ<1

All coordinates scale by (V*n/V*o)1/3. The acceptance exponent is

−[ΔU*+p*ΔV*]/T* + (N+1) ln(V*n/V*o).

The N+1 factor is appropriate because the proposal is uniform in ln V. The physical cutoff stays fixed at 3.5σ—it is not scaled with the box. A proposed box is rejected if L/2 ≤ rc.

8. LAMMPS convention and cross-check

Plain LAMMPS Yukawa uses Uij=Aijexp(−κr)/r. Matching the contact-referenced Fortran form requires

Aij = sij σ exp(κσ).

For σ=1 and κ=6, |A|=e⁶=403.4287934927351: positive for like types and negative for unlike types. Plain LAMMPS Yukawa has no hard core, so first verify that no pair has r<σ.

9. What was modified in the source

  1. ener.f evaluates the signed, contact-referenced Yukawa pair energy and analytic virial.
  2. eneri.f obtains the sign from particle types and applies minimum-image distances.
  3. readdat.f reads κ; mcvol.f keeps rc fixed during volume moves.
  4. Lennard–Jones tail correction and energy shifting are disabled.
  5. Types are preserved in restart and trajectory output.
  6. New metrics record η=πρ*/6 explicitly.

The later clean-replication instrumentation did not rewrite the pair potential or NpT acceptance physics; it added validation, provenance, and clearer diagnostics.
